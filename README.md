# 기출각 — 기출 풀다 보면, 1등급 각

<img src="img/logo.svg" width="72" alt="기출각 로고">

2013–2026년에 시행된 대학수학능력시험과 6월·9월 모의평가의 수학 문항 2,268개를 연도·단원·배점으로 찾아보고, 원하는 문항으로 A4 시험지를 만들 수 있는 정적 웹사이트입니다.

## 기능
- **문제 찾기**: 시험(수능/6월/9월), 연도(시행년도·학년도 표기 전환), 배점, 문항 형식(5지선다/단답), 유형·과목(A/B형, 가/나형, 공통·선택), 단원, 문항 번호, 낱말 검색을 조합해 찾고, 조건마다 문항 수를 보여 줍니다.
- **정답 확인**: 문항을 열고 ①~⑤를 고르거나(키보드 1~5) 단답형 답을 입력하면 바로 채점되고, 맞음·틀림이 자동으로 기록됩니다. ‘정답 보기’로 정답만 볼 수도 있습니다.
- **문항 크게 보기**: ←/→ 키로 넘기기, 시험지에 담기, 즐겨찾기, 맞음·틀림·다시 보기 표시, 메모, 이미지 저장.
- **시험지 만들기**: 담은 문항 끌어서 순서 바꾸기·정렬·섞기, 배점별 개수를 정해 자동 출제(단원 고르게), 2단/1단, 풀이 공간, 문항 번호 새로 매기기, 출처 표시, 성명·번호 칸, 문항 정보표(출처·단원·배점·정답 칸). 인쇄하거나 PDF 파일로 내려받을 수 있습니다. 시험지 양식은 수능·모의고사형과 간단형 중에서 고르고, 한 단에 넣을 문항 수(자동/1~4)와 제목·부제목을 정할 수 있습니다(미리보기에서 바로 수정).
- **저장·공유**: 시험지를 브라우저에 저장하거나 링크로 공유합니다.
- **출제 통계**: 단원 × 연도 출제 문항 수 표. 칸을 누르면 해당 문항으로 이동합니다.
- **내 학습 기록**: 단원별 맞음·틀림 현황, 메모 모아 보기, 기록 백업/불러오기.

학습 기록은 각자의 브라우저(localStorage)에만 저장됩니다.

## 구성
- `index.html`, `css/style.css`, `js/app.js`: 화면과 기능 (빌드 과정 없음)
- `js/data.js`: 문항 목록 (연도, 시험, 유형, 번호, 배점, 단원, 번호 위치, 검색용 본문, 정답). 정답은 한국교육과정평가원 정답표(홀수형) 기준입니다.
- `js/render.js`: 미리보기를 그대로 그려 PDF 만들기 (jsPDF)
- `img/<연도>/<id>.png`: 문항 이미지. id 형식은 `연도-시험-유형-번호` (시험: S=수능, 6=6월, 9=9월 / 유형: A, B, ga, na, c=공통, pr=확률과통계, ca=미적분, ge=기하)

## 출처
문항 · 정답 출처: 한국교육과정평가원 대학수학능력시험 및 모의평가 문제지와 정답표. 문항의 저작권은 한국교육과정평가원에 있습니다. 이 사이트는 비영리 학습용이며 한국교육과정평가원과 관련이 없습니다. 단원 분류는 참고용입니다.
